# Car Price Prediction (ML Project)

## 📊 Problem Statement
Predict car prices based on features like fuel type, transmission, etc.

## ⚙️ Approach
- Data Cleaning & Preprocessing
- Feature Encoding
- Model Building (Linear Regression, Random Forest)
- Model Evaluation (R², MAE, RMSE)

## 📈 Results
- Random Forest R² Score: 0.94
- Linear Regression R² Score: 0.67

## 🛠️ Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib / Seaborn

## 📌 Conclusion
Random Forest performed better than Linear Regression for this dataset.
